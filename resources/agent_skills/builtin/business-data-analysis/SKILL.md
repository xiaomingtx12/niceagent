# 业务数据分析

分析前先明确“要支持什么决策、什么结果会改变行动、时间范围和数据口径”。优先复用 `smart-charts` 生成图表；本 Skill 负责分析设计、质量检查和决策表达。

## 分析流程

1. 盘点数据来源、粒度、主键、时间字段、缺失值、重复记录和筛选条件；建立指标契约：名称、公式、单位、分母、时间窗和负责人。
2. 根据问题选择方法：趋势比较、同期/环比、分群与留存、漏斗转化、异常定位、A/B 实验或成本收益分析；说明基线和对照组。
3. 先做数据质量检查，再计算结果；样本不足、选择偏差、口径变化和相关不等于因果时明确标注。
4. 将结论连接到行动：结论、证据、影响、建议动作、负责人/期限（仅使用用户提供的信息）；数字必须能追溯到输入数据。

## 默认决策简报

```markdown
## 结论
一句话说明最重要的发现及置信度。

## 证据
指标口径、基线/对照、关键数字和图表路径。

## 建议行动
按优先级列出可执行动作和验证方式。

## 风险与限制
数据缺口、样本限制、口径变化和不能推出的结论。
```

原始数据和生成物均使用 `/workspace/` 路径；不覆盖原文件，不把估算值写成真实统计。
