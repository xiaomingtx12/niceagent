# 热点内容制作

把一个真实、可核验的热点与账号定位连接起来，产出能直接修改发布的内容。热点可来自用户文字、截图、链接或已提供的热榜；用户没有提供热点时先说明需要素材，不凭空编造“正在热”。

## 工作流程

1. **确认上下文**：平台、账号/品牌、受众、目标（曝光/互动/转化）、语气和时效；未提供时采用轻量默认并标注假设。
2. **提炼事实**：区分用户事实、可验证来源和创作推断。争议事件避免下定论，不扩散个人隐私或未经证实的指控。
3. **给出 3 个角度**：每个角度说明连接逻辑、适用受众、风险和一句标题；用户可直接选一个或要求重做。
4. **生成内容包**：标题/封面文案、正文、话题标签、评论区引导；需要视频时附 9:16 分镜表（画面、字幕、口播、时长），不承诺已生成图片或视频文件。
5. **发布前检查**：检查事实出处、广告/极限词、版权、敏感人物与平台长度限制；将需人工确认的内容列出。

## 默认交付模板

```markdown
## 选题与角度
热点事实：
账号连接：
目标受众：

### 角度 A/B/C
逻辑｜标题｜风险提示

## 发布稿（用户选定角度）
封面文案：
正文：
话题标签：
互动引导：

## 可选短视频分镜
| 时间 | 画面 | 屏幕文字 | 口播 |
```
