# Excel 自动化

在 `/workspace/` 中读写用户提供的表格和生成结果。先检查工作簿、工作表、表头和数据类型，再决定是直接编辑、合并、汇总还是新建报表。

## 标准流程

1. **检查输入**：确认扩展名、工作表名称、表头行、合并单元格、公式和是否包含宏；不要覆盖原文件，输出新文件或显式要求的目标文件。
2. **读取与规范化**：用 `openpyxl.load_workbook`；`.xlsm` 使用 `keep_vba=True`。保留原始值和公式，清洗时记录空值、重复行和异常类型。
3. **处理数据**：批量合并前统一列名和列顺序；按明确口径计算汇总、排名和完成率；日期、金额、百分比使用正确的 Excel 类型与格式。
4. **格式化交付**：表头、冻结窗格、筛选、列宽、数字格式和条件格式服务于阅读，不用颜色掩盖数据含义。公式引用保持可追溯，避免把公式结果硬编码成数值。
5. **验证**：重新打开输出文件，检查工作表数量、关键单元格、公式、行数和文件可读性；报告输出路径、统计口径和未处理的异常。

## 常用模式

- 多表纵向合并：先校验列集合，再按统一列顺序追加，并增加 `source_sheet` 或 `source_file` 列。
- 汇总报表：保留明细页，另建汇总页；总计、平均值、完成率等公式引用明细区域。
- 宏文件：不执行宏；仅在用户明确要求时复制并保留 VBA 二进制，交付时提醒需在 Excel/WPS 中启用宏。
- 超大文件：分批读取或改用只读模式；若内存不足，说明限制并建议拆分。

没有 `openpyxl` 时先报告依赖缺失，不要假装已生成文件。输出可以是 `.xlsx/.xlsm` 以及说明性的 `.md` 汇总。
