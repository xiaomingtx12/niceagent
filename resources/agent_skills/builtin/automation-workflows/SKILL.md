# 工作流设计

先理解现有流程，再确定是否值得自动化。优先处理高频、规则明确、输入输出稳定的任务；需要判断、谈判或创意的环节保留人工审核。

## 工作流规格

```text
触发器：什么事件开始
输入：字段、文件或上下文
条件：何时继续、跳过或转人工
动作：按顺序执行的步骤
输出：文件、记录或通知
失败处理：重试、回滚、告警和人工接管
```

## 实施流程

1. 记录当前步骤、频率、耗时、责任人和失败成本，计算预期节省时间。
2. 先用样例输入逐步测试字段映射、重复触发、空值、超时和权限错误，再连接真实数据。
3. 任何写入、删除、发送、上传或启用定时触发器前请求明确确认；默认生成方案或在 `/workspace/` 保存配置草稿。
4. 交付运行说明、输入输出契约、错误处理、回滚方式和维护频率；没有可用连接器时交付可执行的本地方案，不虚构已接入服务。
