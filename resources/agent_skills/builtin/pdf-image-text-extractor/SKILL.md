# PDF / 图片文字提取

先识别输入类型和用户要的范围（全文、指定页、表格或某个字段），再提取。默认不改写原文；无法辨认的字符用 `[待确认]` 标记，不猜测数字、金额、日期或编号。

## PDF 流程

1. 用 `scripts/pdf_text_extractor.py <pdf>` 提取文字型 PDF；指定页码时先确认脚本参数并只处理所需页面。
2. 检查输出页数、空页和异常编码；保留标题、段落、列表和页码边界。
3. 若页面几乎没有文字，说明这是扫描件，转为视觉 OCR（若当前模型支持图片输入）；不能 OCR 时明确报告限制。
4. 需要保存时写入 `/workspace/<name>.md`，包含来源文件、页码范围、提取状态和正文；不要覆盖原 PDF。

## 图片与数字校验

视觉 OCR 要覆盖标题、正文、表格、注释和水印。手机号、订单号、金额、日期、身份证号等数字串必须逐位复核；不确定时保留原候选并标注位置，不提供未经确认的“修正值”。涉及个人敏感信息时只输出用户请求的最小范围。

## 交付格式

```text
来源：文件名
范围：页码/区域
状态：完整、部分提取或待 OCR
内容：按原结构整理的文字
问题：空页、模糊字符、表格错位或无法识别项
```

脚本依赖 PyMuPDF。依赖缺失时报告安装需求；脚本报错时先检查路径和文件完整性，不要伪造提取结果。
