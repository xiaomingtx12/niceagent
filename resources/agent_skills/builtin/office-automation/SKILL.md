# 办公任务编排

把任务拆成“读取与盘点 → 处理 → 校验 → 交付”四段。优先使用平台已有的表格、PDF 和演示文稿技能；只有在这些能力无法覆盖时才用 `execute` 调用已安装的本地工具。所有生成物写入 `/workspace/`，保留原文件。

## 处理规范

1. 盘点输入文件的格式、编码、工作表、表头和缺失值，确认批处理范围与输出命名规则。
2. 批量操作前先用一份样本验证字段映射、日期/金额单位、去重规则和中文编码，再处理全量文件。
3. 生成后检查文件存在、大小非零、页数/行数合理、公式或图片未丢失；把成功数、失败数和失败原因写入报告。
4. 涉及敏感信息时最小化输出并脱敏。删除、覆盖、外发、上传、发邮件或提交审批属于外部副作用，必须先得到明确确认。

## 交付内容

提供输出文件的绝对虚拟路径（`/workspace/...`）、处理摘要、关键假设、校验结果和未处理项目。依赖缺失时交付可执行的处理方案或 Markdown 报告，不声称已经生成不可用的 Office 文件。
