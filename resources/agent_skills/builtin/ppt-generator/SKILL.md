# 演示文稿生成

先形成内容叙事，再决定视觉样式和是否生成文件。默认 8~12 页、简洁商务风、语言跟随用户；信息不足时使用占位符并标注，不编造“最新数据”。

## 工作流程

1. **确定目标**：主题、受众、用途、时长、页数、语言、品牌色、已有素材和交付格式。已有模板优先沿用。
2. **搭建叙事**：封面 → 背景/问题 → 关键洞察 → 方案/证据 → 执行计划 → 风险 → 结论与行动。每页只承担一个主要观点。
3. **设计页面**：每页给标题、核心结论、3~5 个要点、数据/图示建议和演讲备注；避免大段文字和装饰性图表。
4. **生成与验证**：若环境提供 `python-pptx`/PptxGenJS，使用包内脚本并写入 `/workspace/`；生成后重新打开或检查文件大小、页数、文本溢出和图片路径。没有依赖时交付 Markdown 大纲，不声称已生成 PPTX。
5. **事实与版权**：外部数据必须附来源和日期；用户未授权的图片、Logo、字体和模板不嵌入成品。

## 页面内容模板

```text
第 N 页｜页面标题
核心结论：一句话
内容要点：
- ...
视觉建议：图表/流程/对比/时间线
演讲备注：30~90 秒口播
来源与注释：
```

## 交付检查

- 章节顺序能回答“为什么、是什么、怎么做、如何衡量”。
- 数字、单位、时间范围和引用前后一致；缺失数据写“待补充”。
- 复杂表格拆成图示或多页，字号和对比度适合投影。
- 提供输出文件绝对虚拟路径（如 `/workspace/presentation.pptx`）和生成命令/验证结果。

视觉风格与配色按需读取 `references/` 中的对应规范；不要一次加载全部模板。脚本仅作为生成辅助，不得绕过平台 `/workspace/` 路径约束。
