# 内容摘要

先确认摘要对象、受众、用途和期望长度。文件摘要先用 `read_file` 读取并识别标题、日期、作者、数据和引用；网页内容只有在运行时提供联网工具时才抓取，不凭记忆补全。

## 摘要方法

1. 抽取主题、结论、关键事实、数字、时间、人物、行动项和不确定性。
2. 删除重复背景和修辞，但保留改变含义的限定词、条件、反例、否定和来源。
3. 按用户要求输出一句话、要点列表、分层提纲或结构化 JSON；没有要求时使用“结论 / 关键要点 / 待确认”三段。
4. 长文先分段摘要，再合并去重；合并后复核数字、专名、时间和因果关系，避免摘要比原文更绝对。

## 默认格式

```markdown
## 结论
一句话概括核心结论。

## 关键要点
- 事实、数据或行动项

## 待确认
- 原文没有说明或存在冲突的内容
```

用户要求压缩字数时优先保留结论、约束、数据和行动项；不凭空添加关键词或评价。
