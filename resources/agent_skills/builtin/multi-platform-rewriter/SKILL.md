# 一键改稿多平台分发

先确认原稿/素材、目标平台、受众、品牌口径、禁用表达和期望行动。没有原稿时先索取素材或明确允许创作的范围。

## 改写流程

1. 抽取原稿的事实、核心观点、证据和不可改动项；事实不足时标注待核验，不补造案例或数据。
2. 按平台分别调整结构、开头、语气、长度和互动方式。默认可输出公众号长文、小红书笔记、抖音口播稿、视频号文案四版；用户可指定子集。
3. 每个平台提供 2~3 个标题、正文、摘要/封面文案、标签和评论区引导，并保持观点一致而非简单缩写。
4. 发布前检查夸大承诺、极限词、版权、隐私、医疗/金融等高风险表述，列出需要人工确认的项目。详细规则按需读取 `references/platform-specs.md` 和 `references/compliance-checklist.md`。

## 交付边界

结果默认直接返回；用户要求保存时写入 `/workspace/`。本 Skill 不执行登录、账号绑定、付费 API 调用、平台提交或自动发布。
