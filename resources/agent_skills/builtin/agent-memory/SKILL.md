# Agent 记忆

本 Skill 只定义长期记忆的整理规则，不定义记忆的存储实现。长期记忆由系统专门的 `/memories/` 机制提供，不是 Workspace 文件；Workspace 只用于项目文件和任务产物。记忆写入前判断信息是否长期有用、是否得到用户明确表达，以及是否含敏感数据。

## 文件布局

```text
/memories/
  MEMORY.md              # 精炼的长期事实与偏好
  projects/<project>.md  # 项目状态、决策和待办
  lessons/<topic>.md     # 可复用经验与失败教训
  logs/YYYY-MM-DD.md     # 当日简短事件日志
```

## 读取与写入

1. 回答涉及历史偏好、项目决定、人员或待办的问题前，先读取 `MEMORY.md` 和相关主题文件；找不到或信息冲突时明确说明。
2. 用户明确要求记住时，提炼为一条可验证事实，附日期和来源上下文，追加或更新对应主题，不重复记录。
3. 任务完成后只记录长期有效的决定、约束和经验；临时闲聊、推测、密码、令牌、身份证号和完整聊天记录不写入。
4. 更新前保留原有事实，发现冲突时标记“待确认”或记录新版本，不静默覆盖；写入后重新读取检查格式和内容。

## 默认输出

回忆类回答区分“记忆中明确记录”“本轮推断”和“未找到”。用户要求删除或修改记忆时，只改指定条目，并报告实际变更的文件。
