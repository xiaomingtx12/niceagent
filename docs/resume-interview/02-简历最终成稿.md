# 简历最终成稿

## 项目名称

NiceAgent 智能体开发与运行平台

## 项目介绍

面向知识问答、资料分析、内容生成及文件处理的智能体开发平台，支持在线配置模型、提示词、工具、Skills、子 Agent、知识库和工作流，通过 WebApp 与开放 API 交付应用。项目从基础对话和工具调用持续迭代至多 Agent 协作、可恢复任务、沙箱执行及自动评估，并将自建 LangGraph Agent 重构为 DeepAgents 运行时。

## 技术栈

Python、Flask、SQLAlchemy、PostgreSQL、Redis、Celery、LangChain、LangGraph、DeepAgents、Weaviate、MCP、SSE、COS、Bubblewrap/Daytona。

简历版面有限时，按目标岗位保留主要技术即可。技术栈中的 Celery 对应评估和文档等后台处理；普通 Agent 执行由平台后台线程承载。

## 项目实现

- **Agent 架构演进与在线装配**：将自建 LangGraph Agent 重构为 DeepAgents 运行时，支持在线配置模型、提示词、工具、Skills 及同步/异步子 Agent，按授权装配能力，通过中间件统一调用校验、重试与次数限制。

- **任务管理与交互恢复**：统一 WebApp/API 任务入口，结合 ask_user、图中断与 Checkpoint 实现暂停及补充输入后的恢复，通过表单校验、提交幂等与执行权控制，防止重复恢复并协调取消冲突。

- **流式事件与断线续传**：规范化模型、工具及任务状态事件，通过 SSE 实时分发与后台批量落库分离交付和存储；以序号游标衔接历史快照与增量事件，支持断线续传，并在结果事务提交后发布终态。

- **上下文工程与长期记忆**：按动静分离组织提示词与本轮输入，稳定前缀并避免重复注入；结合预算管理、摘要压缩和历史归档控制上下文体积，基于 Store 按账号与应用隔离文件记忆，支持按需读写。

- **沙箱执行与文件交付**：统一路由工作区、Skills 和记忆访问，实现沙箱按需创建、会话独占复用及超时回收；支持授权 Skill 压缩上传与安全解包，显式交付产物至 COS，并以版本校验防止旧副本覆盖。

- **在线知识库与混合检索**：支持在线管理文档与分段，构建解析、清洗、分段及索引链路，融合 Weaviate 向量与关键词召回；校验访问权限和向量模型一致性，将检索能力接入 Agent 与工作流。

- **可视化工作流引擎**：将画布节点与连线配置编译为 LangGraph 执行图，实现跨节点变量传递、条件路由与并行汇聚，提供流式调试及草稿发布能力，并将工作流封装为 Agent 可调用工具。

- **Agent 评估与执行验收**：冻结材料与配置，结合 LLM 裁判和规则核验实现历史评分与隔离执行验收；在执行验收中通过 Rubric 驱动评分修订循环，以内容哈希绑定证据，防止新产物沿用旧验收结果。

## 使用说明

上面的内容描述已存在的代码能力，不包含未经测量的性能收益。具体个人分工可放在项目角色字段，不默认添加「独立负责全部」「主导团队」或商业用户规模。

架构演进表示把自建 Agent 层改为基于 DeepAgents 的装配；DeepAgents 底层仍使用 LangGraph，项目工作流也继续使用 LangGraph。沙箱会话池的具体实现以 Daytona 为例，不能把相同生命周期策略套到所有 Provider。
