# 内置插件与应用模板

应用模板按当前 Agent 能力配置，包含 Skills、工具、同步子 Agent、用户问答及文件交付指引。创建时使用当前账号已激活的默认模型，通过与编排页相同的草稿校验解析 Skill 版本和摘要。模板不预绑定其他账号的知识库、工作流或已发布 Agent。

本次升级作用于模板目录及以后新建的草稿；已经添加到个人空间的应用不会自动改写。需要使用新版配置时，可以重新添加模板后在编排页调整。

## 模板目录

应用、插件、工作流与 Skill 模板归入同一个“模板中心”一级入口，使用与个人空间相同的二级分类面板。原有四类 URL 保持可访问，切换时保留搜索关键词。

| 模板 | 主要能力 |
| --- | --- |
| 代码审查助手 | 代码问题定位、结构图、报告交付 |
| API 文档助手 | 接口说明、调用示例、时序图 |
| SQL 分析助手 | 查询编写、业务指标口径、验证方案 |
| 简历优化助手 | PDF 材料提取、岗位匹配、真实经历改写 |
| 英语学习伙伴 | 情景练习、纠错、学习偏好记忆 |
| 工作简报助手 | 日报、周报、会议纪要与行动项 |
| 小红书内容助手 | 内容草稿、多平台改写、自然表达 |
| AI 产品方案助手 | 联网调研、需求整理、流程和验收标准 |
| 专题研究团队 | 研究员检索、核查员复核、带引用报告 |
| 办公文档助手 | 文档/PDF 提取、纪要与办公文件 |
| 业务数据分析团队 | 数据分析员计算、核查员复核、表格与图表 |

文件生成和脚本执行依赖平台启用的沙箱及对应 Skill 所需软件；浏览外部网页还需要沙箱网络可用。任务计划由用户在运行时开启。验收要求由工作台运行配置提供，模板提示词只要求按实际提供的标准检查。

## 插件配置

插件页面的“已配置”仅表示部署参数存在，不代表连接、权限或配额检查通过。目录读取不发起网络请求，不展示凭据值；独立工具初始化无需凭据，缺少配置时在调用阶段提示。

| 插件 | 部署配置 | 应用可配置项 |
| --- | --- | --- |
| SearxNG | `SEARX_SEARCH_URL`，需启用 JSON 搜索 | 返回条数 |
| Google Serper | `SERPER_API_KEY` | 返回条数 |
| 当前时间 | 无 | 查询输入支持 IANA 时区，默认 `Asia/Shanghai` |
| DuckDuckGo | 无 API Key，需网络可达 | 返回条数 |
| DALL-E 3 | `OPENAI_API_KEY`，需模型权限和配额 | 图片尺寸、风格 |
| 通义图像 | `DASHSCOPE_API_KEY`，需模型权限和配额 | 模型、图片尺寸 |
| 高德天气 | `GAODE_API_KEY`，Web 服务类型 | 查询输入为城市或行政区编码 |
| 维基百科 | 无 API Key，需网络可达 | 语言、返回条数 |
| 网页与资料读取 | 无 API Key，需公网可达 | 网页分段、RSS/Atom 筛选、PDF 分页读取 |
| 飞书多维表格 | 无共享环境凭据 | App ID、App Secret、app_token、table_id |
| Notion 工作空间 | 无共享环境凭据 | Integration Token，写入工具还需目标页面 ID |

飞书和 Notion 显示“编排时配置”，在应用插件设置或工作流工具节点填写凭据。凭据是编排配置，使用密码输入，不进入模型调用参数或运行工具序列化；沿用平台现有配置存储，不提供新的凭据保险库。拥有应用配置读取/导出权限的人仍可能读取配置值。

飞书提供字段查询、记录筛选、创建和部分更新四个独立工具，目标表由配置固定。需为飞书自建应用授予相应多维表格读写权限、发布应用并添加目标表格协作者。筛选和字段对象使用 JSON 文本，以兼容现有工作流标量输入，例如 `{"客户名称":"示例公司","状态":"跟进中"}`；写入前先查询表结构，使用真实字段名与类型。

Notion 提供标题搜索、分页读取页面子块、创建页面、追加段落四个独立工具。需将页面连接到集成，授予 Read content / Insert content 等相应权限。读工具可访问集成授权页面；写工具只操作配置的目标页面。API 版本固定为 `2022-06-28`，页面正文按纯文本段落保存，不解析 Markdown。

两类业务插件均不自动重试写入。超时或响应异常时，结果可能未知，应先查询确认以避免重复创建。按实际用途绑定只读或写入工具。商业模板不含密钥，创建后须先配置再使用。

这些是内置工具的部署配置，与账号的聊天模型连接配置分开。显式传给工具工厂的凭据优先于环境变量。密钥不应填写在模板 YAML 中。

搜索工具的结果包含标题、链接和摘要；摘要只用于定位来源，研究任务仍应核对原文。DALL-E 3 保留历史绑定名称，能否使用以外部服务提供的模型权限为准。
