# NiceAgent 项目简历描述（个人负责版）

> 按用户提供的模板补充具体实现和技术难点，依据 2026-09-16 当前代码核对。以下成稿不使用未经测量的性能提升比例；后面的历史演进章节作为面试素材，当前行为以模块实现详解为准。

## 推荐简历版本

**项目介绍：** 一站式 AI Agent 开发与任务执行平台。初期提供多模型接入、RAG 知识库、可视化工作流、MCP 工具及 WebApp、开放 API 发布，后续基于 DeepAgents 升级为任务工作台，支持任务规划、多 Agent 协作、Skills、按需长期记忆与沙箱执行，覆盖应用搭建、复杂任务执行、文件产物交付及独立测评。

**核心技术：** Python、Flask、SQLAlchemy、DeepAgents、LangChain、LangGraph、PostgreSQL、Redis、Celery、Weaviate、Daytona、LangSmith Sandbox、RAG、MCP、SSE、COS、腾讯云 SCF、Edge-TTS、Vue 3、TypeScript。

- **Agent 运行时：** 基于 DeepAgents / LangGraph 统一装配模型、工具、Skills 与持久化资源，支持同步及远程异步子 Agent；通过能力授权、参数校验、选择性重试和主循环调用限制控制执行边界，复用请求内连接查询减少重复装配开销。

- **任务控制与恢复：** 分离会话、Turn、Run 与执行片段，通过会话行锁、消息幂等键和执行标识校验防止重复启动及迟到写入；结合 PostgreSQL Checkpointer、interrupt / Command(resume) 和答案批次去重，实现任务暂停、人工补充后恢复与取消。

- **流式协议与前端性能：** 采用内存实时事件、有界队列和批量落库，结合快照与配套水位实现 SSE 断线恢复；前端通过共享 Markdown Worker、最新正文合并及请求取消／身份校验，减少解析积压和会话切换时的状态串写。

- **Skills 复用与授权：** 实现技能包版本校验、内容摘要和应用绑定，为主／同步子 Agent 提供独立授权的只读目录；复用内容一致的目录，将指令、脚本和参考资料封装为技能，避免重复挂载与越权读取。

- **上下文与提示词：** 分离固定规则与本轮输入，保持提示词及工具定义前缀稳定；结合模型窗口、输出预留和安全余量计算预算，复用原生摘要实现自动／主动压缩，并展示上下文占用、缓存用量和摘要保存状态。

- **记忆与文件交付：** 基于 LangGraph Store 实现账号与应用隔离、按需读取的文件式记忆，通过事务锁、哈希校验和无变化跳过控制并发写入；工作区采用临时副本与显式交付，结合 revision 乐观锁和 COS 保存补偿防止覆盖冲突。

- **沙箱资源管理：** 接入 LangSmith Sandbox 与 Daytona，实现懒初始化和技能包压缩上传；通过进程内会话独占租约、空闲 TTL 与容量淘汰复用 Daytona 实例，利用租约代际校验防止旧定时器误回收。

- **RAG 在线知识库：** 基于 Celery 构建文档解析、切片、Embedding 与 Weaviate 索引链路，支持片段管理、启停和失败记录；提供语义、全文及混合检索，通过 Embedding 指纹防止跨向量空间混检，统一供 Agent 与 Workflow 调用。

- **插件工具集成：** 将 Builtin、OpenAPI、MCP 和发布工作流统一适配为 BaseTool，支持资源授权、参数校验和调试；实现 MCP 工具发现、配置缓存及同步／异步桥接，并仅对指定只读工具自动重试，避免重复写操作。

- **可视化工作流：** 实现前端 DSL 到 WorkflowConfig、StateGraph 的校验与编译，支持 LLM、检索、工具、HTTP、代码等节点及发布后工具化复用；代码节点经 AST 校验后交由腾讯云 SCF 执行，与平台服务进程隔离。

- **Agent 测评与验收：** 基于 Celery 实现历史评分与独立执行验收，冻结材料和配置，通过条件更新保护任务认领与超时状态；结合原文引用、确定性检查和候选哈希核验约束裁判结论，使用原生 Rubric 驱动修订。

## 采用这些表述的依据

- “每次模型调用前刷新记忆”改为按需文件读取，当前未启用记忆全文自动注入。
- “沙箱增量回写”改为临时副本与显式交付，文件工具写入不自动保存到平台。
- Daytona 租约注明进程内管理，不描述成分布式资源调度；空闲容量限制也不等于总并发配额。
- SSE 描述为实时发布与批量持久化，不承诺进程崩溃时未提交尾部零丢失。
- 模型与工具限制注明主循环，不描述为所有子 Agent、所有恢复片段共享的业务总预算。
- LangSimith 修正为 LangSmith；工作流代码执行采用云函数隔离，不宣称 AST 校验能够消除所有代码执行风险。
- 未补造用户量、吞吐、成本降幅或缓存命中提升比例。正式简历可按岗位选择其中 6—8 条，其余留作面试展开。

## 按 Git 演进过程描述项目

### 第一阶段：Agent 与应用平台基础建设

- **完成 Agent 基础能力落地：** 实现基础 Agent、函数调用 Agent、Agent 队列管理和模型调用链路，建立后续 Agent Runtime 的执行基础。

- **完成应用配置和发布模型：** 重构应用模块，增加应用配置、配置版本历史、调试会话和发布配置，支持草稿编辑、调试验证和生产配置隔离。

- **建设知识库与外部能力：** 实现 Dataset 文档处理、向量检索、自定义 API Tool、Workflow 节点、语音能力和长期记忆，扩展 Agent 的知识获取与外部操作能力。

### 第二阶段：LangGraph Agent 能力增强

- **增强 Agent 状态与会话能力：** 基于 LangGraph 的图执行和 Checkpoint 机制完善 Agent 状态管理、历史消息、流式输出、长期记忆和工作流恢复。

- **建设多 Agent 与计划能力：** 抽象 AgentTool、事件冒泡、Supervisor 调度、Team 执行、Plan/Execute/Replan 和 Pipeline Agent，验证多 Agent 协作和任务规划模式。

- **统一多入口调用：** 将调试页、WebApp、开放 API 和内部任务入口接入统一 Agent 服务，同时适配不同身份、配置来源和输出协议。

### 第三阶段：DeepAgents 运行时升级

- **主导 DeepAgents 原生集成：** 将原有 Agent 实现逐步迁移到 DeepAgents，围绕 `AgentConfig`、运行上下文、模型解析、Middleware、工具、SubAgent 和持久化能力重新组织运行时架构。

- **重建 Workspace 和记忆能力：** 接入 Workspace 文件后端、Filesystem Middleware、长期记忆和上下文压缩，使 Agent 能够跨步骤读写文件、保留运行记忆并控制上下文窗口。

- **完善模型和工具兼容：** 增加动态模型发现、Provider Connection、模型兼容 Middleware、MCP Tool、API Tool 和统一事件翻译，屏蔽不同模型和工具协议差异。

- **重构 DeepAgents V2 Runtime：** 将运行时拆分为配置解析、资源装配、执行器、事件规范化、状态投影、持久化和协议适配等边界，降低平台业务代码与底层 Agent 框架的耦合。

## 适合面试重点展开的个人贡献

- **我负责的不只是 Agent 调用：** 从前端配置页面到后端 API、数据库、异步执行、事件流和 Agent 核心运行时均由我负责开发，能够完整解释用户点击配置到 Agent 返回结果的全链路。

- **我经历了真实的架构演进：** 项目不是一开始就使用 DeepAgents，而是从基础函数调用 Agent、LangGraph 图执行逐步演进到 DeepAgents。这个过程中既有新能力建设，也有旧接口、数据模型和前端协议兼容。

- **迁移重点是抽象边界：** 没有让业务层直接依赖某个框架 API，而是抽象 AgentConfig、AgentInvocation、AgentExecutor、AgentEvent 和运行上下文，使模型、工具、记忆、Workspace 和 SubAgent 可以逐步替换和扩展。

- **迁移结果是能力升级：** 运行时从单一 Agent 调用扩展为支持工具编排、文件系统、长期记忆、上下文压缩、SubAgent、多 Agent 和计划执行的自主任务平台。
